Help & Documentation

🚀 Quick Start

  1. Configure Database: Enter your SQL Server credentials above
  2. Add OpenAI Key: Enter your OpenAI API key for LLM generation
  3. Discover Tables: Use the Discovery tab to explore your database
  4. Generate Dataset: Create Q&A pairs using the Generation tab

🔍 Complete Schema Discovery Features

  • Unlimited Discovery: Analyzes your entire database schema without table limits
  • Auto-Discovery: Finds all tables and relationships automatically
  • Smart Filtering: Excludes system tables and temporary data automatically
  • Relationship Analysis: Identifies all foreign key relationships for comprehensive join coverage
  • Complete Coverage: Ensures no business tables are missed in Q&A generation

🤖 Generation Options

  • Whole Database: Auto-discover and analyze all relevant tables
  • Specific Tables: Target particular tables for focused testing
  • Total Questions: Set the total number of Q&A pairs to generate (5-100, default: 25)
  • Max Tables Limit: Configurable limit (default: 12) to prevent LLM token overflow while maintaining quality
  • Smart Selection: When exceeding limit, prioritizes tables with most relationships
  • Question Distribution: Questions are distributed across all selected tables based on relationships
  • Join Emphasis: Generates questions requiring table relationships
  • Sample-Based: Uses real data samples for accurate answers

⚡ Async Processing

  • Background Jobs: Handle large databases without timeouts
  • Progress Tracking: Monitor generation progress in real-time
  • Download Results: Export completed datasets as JSON files
  • Job History: View and manage previous generation tasks

🧮 Token Usage & Costs

  • Real-time Tracking: View exact AI token usage for each generation
  • Cost Estimation: See estimated OpenAI API costs in real-time
  • Detailed Breakdown: Input tokens (your prompt) vs Output tokens (AI response)
  • Model Information: Track which OpenAI model was used
  • Export Data: Token usage included in downloaded JSON files
  • Cost Optimization: Use fewer tables/questions to reduce costs
